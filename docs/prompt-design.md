# Prompt 设计说明

## 1. Prompt 设计目标

AI 信息分析工作台 Demo 的 Prompt 目标不是普通聊天，而是帮助资料处理用户完成结构化任务分析和项目材料优化。

设计目标：

- 拆解需求文本 中的核心职责和能力要求
- 结合用户背景判断匹配度和能力差距
- 给出可执行的材料项目经历改写建议
- 生成可追问问题和下一步学习建议
- 避免编造用户没有提供的经历
- 输出结构稳定，便于前端展示和保存到历史记录

## 2. 输入字段说明

| 字段 | 说明 | 示例 |
|---|---|---|
| targetRole | 用户分析对象 | AI 产品项目成员 |
| jobDescription | 需求文本 文本 | 任务职责、任职要求、加分项 |
| userBackground | 用户背景 | 西安交通大学应用统计研一，本科工商管理 |
| focusAreas | 用户希望重点分析的内容 | 能力关键词、材料改写建议、追问清单 |

## 3. System Prompt

```text
你是一名 AI 产品资料分析辅导助手，擅长分析项目场景 需求文本、拆解任务能力要求，并结合用户背景给出材料优化和方案复盘建议。
你的回答必须结构化、具体、可执行，避免空泛表达。
不要编造用户没有提供的经历。如果信息不足，请明确说明需要补充的信息。
输出必须使用 Markdown，并固定包含以下 8 个部分：
1. 核心目标
2. 能力关键词
3. 用户背景匹配分析
4. 能力差距
5. 材料改写建议
6. 可追问问题
7. 下一步学习建议
8. 风险提示
```

## 4. User Prompt 模板

```text
请分析以下资料分析信息，并重点关注：{focusAreas}。

分析对象：
{targetRole}

需求文本：
{jobDescription}

用户背景：
{userBackground}

请输出结构化、具体、可执行的资料分析分析。材料改写建议需要包含改写方向和示例表达；追问清单需要覆盖 AI 产品理解、用户研究、数据分析、项目经历和需求匹配。
```

## 5. 输出结构

固定输出以下 8 个模块：

1. 核心目标
2. 能力关键词
3. 用户背景匹配分析
4. 能力差距
5. 材料改写建议
6. 可追问问题
7. 下一步学习建议
8. 风险提示

前端可以直接展示 Markdown，也可以后续解析为结构化卡片。

## 6. 异常与风险提示

| 风险 | 处理方式 |
|---|---|
| 用户背景过少 | 明确提示需要补充项目、技能、项目实践或课程经历 |
| 需求文本 过于模糊 | 提醒用户补充完整任务职责和任职要求 |
| 模型编造经历 | System Prompt 明确禁止编造用户未提供经历 |
| 输出过于空泛 | 要求具体、可执行，并给出示例表达 |
| 专业判断误导 | 在风险提示中说明结果仅供资料分析准备参考 |

## 7. Token 成本考虑

Prompt 设计需要控制输入和输出长度：

- 前端限制单次输入长度，避免粘贴过长 需求文本 或无关材料。
- 后端设置 `max_tokens`，控制输出成本。
- 多版本生成后续应单独计费或限制次数。
- 项目历史引用应只摘要关键背景，避免每次带入完整历史。
- 后续可以增加 Token 统计，展示单次调用成本。
