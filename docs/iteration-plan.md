# 迭代优先级

本文件用于记录核心功能的优先级判断，包括用户价值、实现难度、商业价值和 P0/P1/P2 迭代安排。

## 1. 优先级判断标准

本项目以「AI 创作助手工作台」为目标形态，优先级主要由以下因素决定：

- 用户痛点强度：是否解决用户当前最频繁、最明确的卡点
- 任务频率：是否对应高频创作、求职和办公场景
- MVP 必要性：是否支撑产品从“聊天工具”升级为“创作工作台”
- 实现复杂度：是否适合在早期版本中快速验证
- 商业化潜力：是否能形成用户愿意付费的效率或专业能力

## 2. 用户痛点到功能机会

| 痛点分类 | 典型用户 | 功能机会 |
|---|---|---|
| Prompt 门槛高 | 求职学生、内容创作者 | 场景化 Prompt 模板、表单化输入、示例提示词 |
| 生成结果不可直接用 | 求职学生、主播、运营实习生 | 快捷改写、多版本生成、结构化编辑区 |
| 专业内容不可信 | 金融专硕、证券新人 | 来源提示、风险提醒、人工确认 |
| 历史内容难复用 | 求职学生、运营、职场用户 | 项目化历史、标签、收藏、搜索、版本管理 |
| 创作流程断裂 | 内容创作者、运营用户 | 工作台式编辑、导出、模板复用和多格式承接 |
| 付费价值感不清晰 | 高频创作者、职场用户 | 高级模板、批量生成、项目管理、专业场景能力 |

## 3. 需求优先级表

| 优先级 | 功能需求 | 主要场景 | 用户价值 | 实现判断 |
|---|---|---|---|---|
| P0 | 场景化 Prompt 模板 | 求职、内容创作、运营办公 | 降低用户表达需求的门槛，让新手也能开始高质量生成 | 适合 MVP，依赖模板设计和基础生成能力 |
| P0 | 快捷改写与多版本生成 | 简历、脚本、方案、文案 | 解决生成结果“还不能直接用”的问题，提高可交付性 | 适合 MVP，交互简单、感知强 |
| P0 | 结果结构化编辑区 | 所有创作任务 | 承接生成后的修改、整理和导出，让产品具备工作台雏形 | 适合 MVP，是区别于普通聊天框的关键 |
| P1 | 岗位 JD 解析链路 | 学生求职、实习准备 | 将岗位理解、能力差距、简历改写和面试准备串成连续流程 | 场景价值高，适合作为首个深度模板 |
| P1 | 账号风格模板 | 短视频、直播、新媒体运营 | 保存账号定位和语气，减少 AI 内容模板感 | 需要用户配置和历史沉淀，适合第二阶段 |
| P1 | 项目化历史管理 | 求职、运营、职场办公 | 按项目保存背景、产出、版本和素材，降低复用成本 | 工作台长期价值核心，但信息架构需设计 |
| P1 | 专业内容核验提示 | 金融、证券等专业办公场景 | 提醒用户核验高风险内容，提升专业场景信任感 | 需要设计边界提示，先做轻量版本 |
| P2 | 视觉辅助生成 | 海报、封面、PPT | 承接视觉内容生成，拓展多模态能力 | 依赖图片/编辑能力，后续迭代 |
| P2 | 团队协作与共享 | 职场团队 | 支持多人共用项目、模板和素材 | 适合商业化阶段，不作为 MVP 必选 |
| P2 | 数据看板与效果追踪 | 新媒体运营、业务运营 | 帮用户评估内容产出和模板使用效果 | 需要数据接入或人工记录，后置验证 |

## 4. MVP 范围建议

MVP 应聚焦“低门槛输入 + 可修改结果 + 可保存复用”三件事：

1. 首页提供高频场景入口：岗位 JD 解析、简历润色、视频脚本、运营方案、会议纪要。
2. 每个场景使用表单化 Prompt，要求用户补充背景、目标、风格和输出格式。
3. 生成结果进入结构化编辑区，支持快捷改写、多版本生成、复制和导出。
4. 支持基础项目保存，例如按“求职岗位”“视频选题”“运营项目”归档。
5. 对金融、证券等专业内容增加轻量提示：AI 输出需人工核验，关键结论建议补充来源依据。

## 5. 后续迭代方向

P1 阶段重点强化场景深度和长期复用，包括岗位 JD 解析链路、账号风格模板、项目化历史管理和专业核验提示。

P2 阶段再扩展视觉、协作和数据能力，例如课件辅助生成、团队模板共享、内容效果追踪和更完整的会员权益体系。
