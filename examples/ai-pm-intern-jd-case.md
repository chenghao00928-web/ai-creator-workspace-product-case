# AI 产品经理实习生 JD 分析案例

## 1. 示例岗位

AI 产品经理实习生

## 2. 示例 JD

岗位职责：

- 参与 AI 助手类产品的用户研究、竞品分析和需求梳理
- 协助完成 Prompt 设计、产品原型、PRD 和功能验收
- 跟踪大模型产品趋势，整理 AIGC 产品体验和能力差异
- 结合用户反馈和数据指标，提出产品优化建议
- 与设计、研发、算法团队沟通，推动功能上线和迭代

任职要求：

- 本科及以上学历，产品、数据、统计、计算机或相关专业优先
- 了解 ChatGPT、Claude、Gemini、豆包、Kimi 等 AI 产品
- 具备用户研究、竞品分析、逻辑表达和文档撰写能力
- 对大模型、Prompt、AI Agent 或 AIGC 工具有兴趣
- 有数据分析、产品原型或项目作品集经验者优先

## 3. 示例用户背景

- 西安交通大学 应用统计研一
- 本科工商管理
- 目标岗位：AI 产品经理实习
- 有数据分析基础，正在补 AIGC 产品理解和作品集
- 已完成「AIGC 竞品分析与 AI 求职工作台 Demo」项目，包括竞品分析、用户访谈、PRD、低保真原型、API Demo 和 Token 成本测算

## 4. 模型输出示例

### 4.1 岗位核心职责

- 做 AI 产品的用户研究和竞品分析
- 将用户痛点转化为产品需求和 PRD
- 参与 Prompt 设计和 AI 功能体验优化
- 关注数据指标和用户反馈，推动产品迭代
- 与研发、设计、算法团队协作

### 4.2 能力关键词

- AIGC 产品理解
- 竞品分析
- 用户研究
- Prompt 设计
- PRD 写作
- 原型表达
- 数据分析
- 跨团队沟通

### 4.3 用户背景匹配分析

用户具备应用统计背景，适合突出数据分析、指标意识和逻辑拆解能力。本科工商管理也可以作为对业务理解和管理基础的补充。当前作品集项目覆盖竞品分析、用户访谈、PRD、原型和成本测算，和 AI 产品经理实习岗位要求匹配度较高。

### 4.4 能力差距

- 真实上线项目经验不足
- 可点击原型和真实用户测试记录还可以增强
- 对模型 API、Token 统计和工程实现理解仍可继续补充
- 简历中需要把统计背景和 AI 产品能力更强地关联起来

### 4.5 简历改写建议

改写前：

> 完成 AI 创作助手工作台产品方案，包含竞品分析、用户研究和产品设计。

改写后：

> 独立完成「AIGC 竞品分析与 AI 求职工作台 Demo」作品集项目，分析豆包、Kimi、通义千问、ChatGPT、Claude、Gemini 等国内外 AIGC 产品，访谈 7 位潜在用户，提炼 Prompt 门槛、结果不可用、历史难复用等痛点，并设计 AI 求职工作台 MVP，输出 PRD、低保真原型、DeepSeek API Demo 和 Token 成本测算。

## 5. 简历改写前后对比

| 版本 | 表达 |
|---|---|
| 改写前 | 做了一个 AI 产品分析项目 |
| 改写后 | 独立完成 AIGC 产品作品集项目，覆盖竞品分析、用户研究、MVP 设计、PRD、原型、API Demo 和商业化测算 |

优化点：

- 明确项目名称
- 写出竞品和用户研究数量
- 突出 AI 产品关键词
- 增加 API Demo 和 Token 成本测算，体现落地意识

## 6. 面试问题清单

1. 你为什么选择做 AI 求职工作台，而不是继续做泛 AI 创作工具？
2. 你分析国内外 AIGC 产品后，最大的产品启发是什么？
3. 这个 Demo 为什么选择 DeepSeek API？
4. 你如何设计 System Prompt，避免模型输出空泛？
5. 如果用户输入的 JD 很短，你会如何处理？
6. 你怎么判断 MVP 只聚焦求职学生？
7. Token 成本测算对产品设计有什么帮助？
8. 如果继续迭代，你会优先做可点击原型、真实用户测试还是模型切换？

## 7. 这个案例如何用于作品集展示

- 左侧放示例 JD 和个人背景
- 中间放 AI 求职工作台 Demo 截图
- 右侧放输出摘要：能力关键词、能力差距、简历改写建议、面试问题

页面标题可以写：

> 示例案例：AI 产品经理实习生 JD 解析

这页可以证明项目不是停留在概念方案，而是能围绕真实求职场景跑通一个 AI 产品 Demo。
